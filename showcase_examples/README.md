# 展示案例

本目录共选取 6 张山区影像问题或困难样例、6 组城市视觉较好的预测案例。

- `mountain_issues`：M01–M06，只有原始 RGB 裁块，没有对山区运行模型，也没有生成山区预测掩膜。
- `city_good`：C01–C06，每组包含原图、预测掩膜、红色轮廓图和三列对照图；C05、C06 为用户指定的深色水体案例。
- 两张 `overview.jpg` 总览图已经排版并加中文编号，可直接插入展示材料。
- 山区 M01–M06 已从原始影像扩大裁切为 1024×1024，完整保留之前所选的 512×512 区域，没有补边。
- 城市独立原图、掩膜和标记图仍为原始像素尺度的 512×512；三列对照图为 1536×564。总览图按版面缩略显示，单张 PNG 保留完整分辨率。
- 城市掩膜白色表示预测阴影，黑色表示背景；红线表示预测阴影的外轮廓。
- 城市案例是人工按视觉效果挑选的局部结果，仍有少量漏检和边界误差；没有真值，不能据此宣称定量指标优秀。
- C05 对应 `image_1_rectified_r00512_c03584`，C06 对应 `image_1_rectified_r00000_c01024`，沿用已有预测。两例可展示深色水面主体保持为背景、邻近阴影仍有响应；C06 顶部保留输入影像黑色边界。水面内区示意多边形记录在 `selection.json` 中，仅用于案例核查，不是真值标注。
- 山区的偏蓝、过暗、高反差按可见现象命名，不据此认定其物理成因，也不将自然地形阴影全部视为数据错误。
- 16 位影像使用固定的整幅有效像素 p2/p98 显示拉伸转为 RGB，没有单独调整某个裁块的颜色。具体参数、源路径及坐标见 `manifest.csv`。
- 原始数据与已有推理结果均未修改。

## 原始 RGB、全色图与融合结果核查

`source_check` 保存第 7 组 M01、M02 对应区域的原始多光谱、原始全色及融合影像对照。优先查看 `M01_scene1_comparison.jpg`、`M02_scene1_comparison.jpg`，两张均对应 2024-12-31。

这两处原始多光谱 RGB 在融合前已经明显偏蓝。原始 TIFF 标签明确为 BLUE/GREEN/RED/NIR，显示使用 R/G/B 三个可见光波段，未使用近红外代替蓝色。原始 RGB 对照共用同一线性 DN 标尺，避免逐通道拉伸造成判断偏差。

M01 蓝区原始 R/G/B 的 DN 中位数约为 12/16/102，M02 约为 23/35/141。全色 PAN 为单通道灰度图。融合会改变局部亮度，尤其部分暗区进一步变暗，但偏蓝现象在原始多光谱中已经存在。此结论针对选中的样例，不能直接推出所有山区均如此，或仅凭未定标 DN 判断物理成因。

对照图从左到右为：未融合原始 RGB、全色 PAN、与原始 RGB 共用标尺的融合图、独立亮度显示的融合图。黄色多边形是 1024×1024 展示区在原始源图中的范围。
